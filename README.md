# Sim-quick-Process-Analysis
SimQuick Call Center Analysis

For this industrial class project, I used SimQuick and Excel to compare five call center staffing levels under normal and increased demand. I looked at customer waiting times, service levels, and employee utilization to identify bottlenecks and recommend staffing changes.

The results suggested that three customer service agents were a reasonable choice for normal demand. During increased demand, supervisor capacity became the main bottleneck, so adding more regular agents alone did not solve the problem.

This repository includes the simulation workbook, analysis report, results, and a comparison chart.
